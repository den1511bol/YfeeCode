Решение: в блоке pip использовать options("--no-deps") и перечислить зависимости вручную с версиями, которые есть в репозитории Chaquopy или чистые из PyPI: requests, urllib3, charset-normalizer, idna, certifi, pyTelegramBotAPI==4.21.0, aiogram==2.25.2, Babel, magic-filter, aiohttp==3.10.10, aiohappyeyeballs, aiosignal, attrs, frozenlist, multidict, yarl, propcache, pyrogram==2.0.106, pyaes, pysocks, tgcrypto (смотреть список wheel на chaquo.com/pypi-13.1/<имя>/). aiogram 3 во встроенном Python невозможен (pydantic-core нет в репозитории Chaquopy).
