# 𝒴𝒻𝑒𝑒𝒞𝑜𝒹𝑒 (YfeeCode)

Мобильная мини-IDE для Android: редактор с подсказками, своя клавиатура, терминал,
запуск Python-ботов Telegram на телефоне.

**Developer: @yfeeeee**

## Сборка
1. Залей проект в GitHub-репозиторий (ветка `main`).
2. Вкладка **Actions → Build APK → Run workflow** (или просто push).
3. Готовый APK: артефакт `YfeeCode-debug-apk` внизу страницы запуска.

## Возможности
- Редактор: подсветка Python/JS/HTML/CSS/C++/C#, нумерация строк, undo/redo.
- Своя клавиатура (EN/RU/символы + ряд скобок, Tab, стрелки). Системная не используется.
- Автоисправление: двойные пробелы, автоотступ, автозакрытие скобок/кавычек,
  кнопка «Исправить файл» (табы, хвостовые пробелы, кривые отступы Python).
- Офлайн-подсказки по Python, JS, HTML, CSS, C++, C#.
- Терминал: `sh`-команды, Python REPL, `run файл`, `stop`, `mod файл.py .cmd`.
- Команды для ботов: `status`, `log err`, `log find слово`, `autorestart on|off`, `backup`, `new telebot|aiogram|aiogram3|flask|hikka имя`, `find слово`, `reqs файл.py`, `tokencheck`, `procfile`, `gitignore`, `snip`, `theme`; в Linux: `yfee-clone`, `yfee-gitpush`, `yfee-py`.
- Python-боты (pyTelegramBotAPI, aiogram 2.x, pyrogram, requests) запускаются в отдельном
  процессе с уведомлением; «стоп» убивает процесс.
- JS запускается в WebView (fetch есть, Node/npm — нет). HTML — кнопка «Просмотр».
- Песочница модулей Heroku/Hikka: `mod mymod.py .hello arg` вызывает команду без Telegram.

## Новое
- Вкладки открытых файлов, выделение текста (копия/вырезать/вставка), поиск и замена,
  переход к строке, комментирование и дублирование строк.
- Шаблоны: боты telebot/aiogram/pyrogram, модуль Heroku, JS-бот, HTML, C++, C#.
  Токен бота читается из `token.txt` рядом со скриптом.
- Зажатие Backspace и стрелок повторяет нажатие.
- Свой шрифт: положи `.ttf` в `app/src/main/res/font/` и подключи через `FontFamily(Font(R.font.имя))`.

## Удобство и обновления
- **Автообновление:** при запуске приложение проверяет релиз `latest` на GitHub, в фоне скачивает новый APK
  и предлагает установить (файлы и настройки сохраняются). Ключ подписи один на все сборки (`app/yfeecode.jks`).
- **Автопробелы:** `name=Аня` → `name = Аня`, `a,b` → `a, b`, `+=`, `==`, `!=`, `<=`, `=>`, `->`, `i++`
  (не в строках и комментариях; `f(a=1)` в Python остаётся без пробелов). Переключатель в настройках.
- **Подсказки в терминале:** кликабельные слова (команды, файлы, ключевые слова, модули). Нажатие дописывает слово
  в строку и ничего не отправляет, так что команду можно собрать из частей.
- **Бот в фоне:** отдельный процесс с WakeLock и WifiLock, автоперезапуск после остановки системой,
  уведомление с последней строкой лога и кнопкой «Остановить». Разреши работу в фоне, когда Android спросит.
- **Интернет в терминале:** `get https://адрес/файл [имя]` скачивает файл в текущую папку.
- **Запуск C++ и C#** кнопкой ▶ или `run файл.cpp`: код компилируется онлайн через Wandbox, а после `linux setup` / `linux dotnet` офлайн (ввод работает только при офлайн-запуске через Linux).
- Подсветка парных скобок, выбор цвета акцента, сплэш-экран.

- **Новое в редакторе и Linux:** касание в любом месте ставит курсор, белый курсор, «символы» (прыжок по функциям и классам), «Aa» и «назад» в поиске, Tab в терминале, `yfee-bot`, `yfee-hikka`, `yfee-git-setup`, `yfee-help`, `yfee-venv`, `yfee-keepalive`, `yfee-pg`, кнопка ⌨ для скрытия клавиатуры, копирование вывода терминала.

- Курсы: Python (41 урок), JS (32), HTML (17), CSS (18), C++ (31), C# (30), Боты и Heroku (47), всего 216 уроков, около 2200 заданий (сборка, выбор ответа, пропуски, исправление ошибок, ввод) и 191 практика. Есть режим «📖 Теория» для чтения без упражнений.

- Практические задания в редакторе (104 штук): Python запускается и проверяется по выводу,
  остальные языки проверяются по структуре кода.

## Оформление
- Чёрно-фиолетовая тема с узорами и мягкой пульсацией (отключается в настройках).
- Настройки: размер шрифта, пульсация узоров, цвет акцента.
- Подсветка парных скобок, быстрые команды-кнопки в терминале.

## Ограничения
- C++ и C# только редактируются (запуска нет).
- Песочница модулей — упрощённая заглушка, не настоящий фреймворк.
- Свой пакет pip добавляется в `app/build.gradle.kts` → `chaquopy { pip { install(...) } }`.

## Быстрый старт для бота
1. Вкладка «Файлы» → «Шаблон» → «Бот: pyTelegramBotAPI» (или aiogram / pyrogram).
2. Вкладка «Терминал»: команда `token 123456:ABC...` сохранит токен в `token.txt` рядом с ботом.
3. В редакторе нажми ▶ или в терминале `run bot_telebot.py`. Остановка: `stop` или «■ стоп».
4. Модуль Heroku: шаблон «Модуль Heroku», затем `mod MyMod.py .hello` — проверка команды без Telegram.
5. Резервная копия: «ZIP↑» в файлах; восстановление: «ZIP↓».
