# Changelog — YfeeCode (developer: @yfeeeee)

## Автосессия 1
- Автосохранение файлов (через 1.5 с после правки и при уходе с вкладки).
- Открытые вкладки и активный файл восстанавливаются после перезапуска.
- Реальная проверка синтаксиса Python (ast) с номером строки, тап по ошибке ведёт к строке.
- Настройки (шестерёнка в шапке): размер шрифта редактора, выключатель пульсации узоров.
- Фикс: на клавиатуре появились одиночные скобки ( ) [ ] { } и кавычки; автозакрытие пары при вводе открывающей и перепрыгивание при вводе закрывающей.

## Автосессия 2
- Панель автодополнения над клавиатурой: слова из ключевых слов языка и из файла, плюс сниппеты (def, class, for, if, try, main, tg — бот telebot, mod — модуль Heroku; для JS/HTML/CSS/C++/C# свои).
- Файлы: ZIP-экспорт и импорт всего проекта (резервная копия, передача знакомому). Терминал: кнопка «очистить».

## Автосессия 3
- Выделение: двойной тап выделяет слово, долгое нажатие включает режим выделения.
- Файлы: поиск по всем файлам проекта, тап по результату открывает файл на нужной строке.
- Практика: решения задач сохраняются автоматически, «Сбросить» возвращает заготовку.

## Автосессия 4
- Python-курс: 3 новых урока (словари и файлы, классы и объекты, асинхронность и aiogram) и 3 практики (класс Dog, сумма значений словаря, async main).

## Автосессия 5
- Стабильность: ошибки Python-вызовов (REPL, модули Heroku, проверка практики, запуск бота) больше не роняют приложение, а показываются в терминале/вердикте.
- Терминал: команда `token ТОКЕН` сохраняет токен в token.txt (в эхо маскируется). README: быстрый старт для бота.

## Автосессия 6
- Подсказки Python для ботов: токен прямо в коде, нет polling/start_polling, time.sleep в async, нет @loader.tds, await вне async def, open без with.
